Agent 常见架构

Profile Planning Memory Tools Action Observation Orchestration
核心理解：Agent 不只是一次 LLM 调用，而是围绕“目标、计划、工具执行、观察结果、继续决策”形成循环。

和 Spring AI 项目的对应关系

Tools：例如 DatabaseTools、检索工具、SQL 执行工具。

Action：模型发起 Tool Calling，并实际执行方法。

Observation：工具执行结果返回模型，模型再决定下一步。

Orchestration：由 Tool Calling Loop / Advisor / Agent 层负责串联多轮调用。

Memory / Planning：如果项目还没有显式的长期记忆与任务拆解，这两部分通常还需要补充。
